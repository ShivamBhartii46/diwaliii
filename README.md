## 🌟 About The Project

**Diwali — A Festival of Lights** is an interactive web experience created to spread happiness, positivity and festive vibes.

Instead of sending an ordinary greeting message, this project lets people experience a series of beautiful festive screens, enjoy animated fireworks and create personalized Diwali greetings to share with their loved ones.

The idea is simple: make Diwali greetings more memorable through creativity and technology! ❤️

## ✨ Features

- 🪔 Beautiful Diwali-themed interface
- 🎆 Animated fireworks and festive effects
- 🚪 Interactive welcome and golden gate experience
- 🙏 Festive blessings and wishes
- 🌙 Beautiful night-sky experience
- 💌 Personalized Diwali greetings
- 🔗 Shareable greeting links
- 📱 Responsive design for different screen sizes
- 🔔 Interactive sound effects

## 🛠️ Built With

This project was created using:

- **HTML5** – Structure of the website
- **CSS3** – Styling, animations and visual effects
- **JavaScript** – Interactions and functionality
- **SVG** – Custom illustrations and graphics
- **GitHub Pages** – Website hosting

## 💻 Run Locally

Want to explore or modify this project on your computer?

1. Clone this repository:

   ```bash

   ```

2. Open the project folder.

3. Open `index.html` in your browser.
